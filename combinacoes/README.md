# Laboratório de combinações

Atividade pública de 10 questões adaptada a celulares, com seleção de turma (3º 1 e 3º 2) e nome carregado do Supabase, conforme autorização do proprietário.

- `index.html` e `atividade.html`: interface completa no GitHub Pages, com campos de 16 px, alvos de toque de pelo menos 44 px e áreas seguras de tela.
- Banco de dados: Supabase, projeto `jzepdmolnoobgbgdavyf`.
- A interface consulta `/api/atividade` no servidor do Site, que mantém a credencial privada fora do navegador e do GitHub.
- O painel `/professor` exige a conta autorizada. A identificação pelo nome é autodeclaração e não comprova identidade.

Nenhuma lista de alunos, chave de serviço ou resposta dos alunos está armazenada neste repositório. Os nomes são consultados durante o uso.
