# Laboratório de combinações

Atividade de 10 questões adaptada a celulares, com seleção de turma (3º 1 e 3º 2) e nome carregado do Supabase.

- `index.html`: entrada publicada no GitHub Pages, com acesso à atividade hospedada.
- `atividade.html`: interface completa, com campos de 16 px, alvos de toque de pelo menos 44 px e áreas seguras de tela.
- Banco de dados: Supabase, projeto `jzepdmolnoobgbgdavyf`.
- A interface consulta `/api/atividade` no servidor do Site, que mantém a credencial privada fora do navegador e do GitHub.
- O painel `/professor` exige a conta autorizada. A identificação pelo nome é autodeclaração e não comprova identidade.

A liberação anônima da atividade depende de autorização do proprietário para exibir a lista de nomes. Enquanto o Site estiver privado, use o botão da página inicial e uma conta autorizada. O arquivo `atividade.html` precisará da liberação do servidor para uso direto pelo GitHub Pages.

Nenhuma lista de alunos, chave de serviço ou resposta dos alunos está armazenada neste repositório.
