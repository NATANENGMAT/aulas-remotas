Tabelas e GráficosTabela organiza. Gráfico mostra.

Tabela

Organiza os dados em faixas ou categorias. Frequência absoluta = contagem. A soma das frequências dá o total.

Frequência relativa

freq. absolutatotal   ex.: 820 = 40100 = 0,4 = 40%

Histograma

Dados em faixas de números. Barras coladas, porque o dado é contínuo.

Colunas

Compara categorias. Barras separadas. A coluna mais alta é a moda.

Setores (pizza)

Partes de um todo: 100% = 360°. Ângulo = frequência relativa × 360°.

Linhas

Evolução no tempo. Sobe = aumentou. Mais inclinada = mudança mais rápida.

Pegadinha dos eixos

O eixo começa no zero? Leia os números do eixo antes de comparar.
