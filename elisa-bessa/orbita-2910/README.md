# Órbita — competição de coordenadas

Atividade remota de 28/10/2026 para 9º 1, 9º 2 e 9º 4.

Entrada pela lista oficial do Supabase, treino guiado, largada 3–2–1 e dez resgates. Partidas ilimitadas. Cada aluno aparece uma única vez no ranking da própria turma, com o melhor resultado: mais acertos de primeira sem dica; menor tempo como desempate. Empates exatos compartilham posição. Energia visual não é o critério do ranking.

O Supabase valida cada resposta e registra erros, dicas e tempo no servidor. Resultados de teste do professor são excluídos do ranking. Não há partidas simuladas de alunos.

A escolha do nome não usa senha individual; cada aluno deve selecionar o próprio nome. O treino é lembrado por aluno neste navegador. O melhor resultado fica associado ao cadastro no Supabase, mesmo ao trocar de aparelho.

Arquivos estáticos servidos pelo GitHub Pages. A função orbita-2910 atende a lista, sessões, partidas e ranking no projeto Supabase autorizado. Apenas a chave publicável aparece no navegador; a chave privilegiada permanece no servidor.

Fontes: licenças em FONT-LICENSES.txt. Música e efeitos originais sintetizados no navegador, com botão para silenciar.

Na competição, cada acerto abre automaticamente o próximo resgate; o último abre o resultado. O treinamento mantém avanço manual para permitir leitura.
