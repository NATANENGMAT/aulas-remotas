ETAPA 1 • DEFINIÇÃO

O que é um sistema linear 3×3?

✍️ COPIAR NO CADERNO

Sistema linear 3×3 é um conjunto de três equações lineares com três incógnitas. Resolver o sistema é encontrar os valores das três incógnitas que tornam verdadeiras as três equações ao mesmo tempo.

EXEMPLO
x + y + z = 6
2x − y + z = 3
3x + 2y − z = 4
3 equaçõesuma em cada linha
3 incógnitasx, y e z
Lineargrau 1
ETAPA 2 • INCÓGNITAS

As letras podem mudar

Os coeficientes são os mesmos. Só muda o nome das incógnitas.

MESMOS COEFICIENTES • OUTRAS INCÓGNITAS
Importante: o que define o sistema 3×3 é ter três incógnitas diferentes, três equações e todas serem lineares.

ETAPA 4 • ESCALONADO

Como reconhecer um sistema escalonado?

✍️ COPIAR NO CADERNO

No sistema escalonado, as incógnitas vão desaparecendo nas linhas de baixo, formando uma escada. Para resolver, começamos pela equação que possui apenas uma incógnita e fazemos a substituição de baixo para cima.

OBSERVE A ESCADA
x + y + z = 6
2y + z = 7
3z = 9
1º z→2º y→3º x
